# VOID Rating v1

Эвристическая оценка вклада игрока в конкретный матч (0–100, 50 — средний уровень). Это не официальный рейтинг Valve.

**Роли.** В каждой команде по net worth: трое лидеров — core, двое остальных — support. Если данных нет — роль «не определена».

**Нормализация.** Каждый показатель сравнивается с игроками той же роли в этом матче: score = 50 + 20·z, обрезается до 0–100 (z — отклонение от среднего в долях стандартного отклонения; для смертей знак инвертирован). Минуты матча учитываются через показатели «в минуту».

| Категория | Показатели (вес внутри категории) |
|---|---|
| Бой | урон по героям/мин (0.5), убийства/мин (0.2), смерти/мин, инвертировано (0.3) |
| Экономика | GPM (0.5), XPM (0.3), добитые крипы/мин (0.2) |
| Командная игра | доля участия в убийствах команды (0.6), помощь/мин (0.2), лечение/мин (0.2) |
| Здания | урон по зданиям/мин (1.0) |

**Веса категорий.** core: бой .35, экономика .30, команда .20, здания .15. support: бой .20, экономика .10, команда .50, здания .20. Не определена: .30 / .25 / .30 / .15. Недоступные показатели и категории исключаются, веса пересчитываются; доля использованных показателей выводится как полнота данных.

**MVP.** Игрок с наивысшим рейтингом среди победителей. Если рейтинг посчитать нельзя — лучший KDA среди победителей (помечается явно).

**Ограничения.** Нет данных о вардах, станах, видении и позициях. Формула — разумная эвристика, веса не калибровались на большой выборке; изменение формулы повышает версию.
