# VOID Rating v2

Эвристическая оценка вклада игрока в конкретный матч (0–100, 50 — средний уровень). Это не официальный рейтинг Valve.

**Роль и позиция.** В каждой команде по богатству определяются трое кор и двое саппортов. Если есть данные реплея о линиях (`lane_role`) и ровно один игрок на миде, он считается кором (позиция 2), два самых богатых из остальных — кор (позиции 1 и 3 по линии), остальные — саппорты (позиции 4 и 5). Без данных о линиях позиция не показывается.

**Оценка показателя.** Показатель переводится в шкалу 0–100 двумя способами и смешивается:
- с нормой героя: процентиль по бенчмаркам OpenDota (`/benchmarks`), только для GPM, XPM, добитых крипов, убийств, урона по героям и лечения в минуту. Если у героя бенчмарк бесполезен (например, лечение у не-лекаря), он не используется;
- с игроками той же роли в этом матче: `50 + 20·z`, обрезается до 0–100 (для смертей знак инвертирован).

Итог показателя: `0.6 · норма героя + 0.4 · матч`, а без бенчмарка — только матч.

| Категория | Показатели (вес внутри категории) |
|---|---|
| Бой | урон по героям/мин (.45), убийства/мин (.20), смерти/мин (.35, инвертировано) |
| Экономика | GPM (.45), XPM (.30), добитые крипы/мин (.25) |
| Команда | участие в убийствах (.50), помощь/мин (.20), лечение/мин (.15), участие в командных боях (.15) |
| Здания | урон по зданиям/мин (1.0) |
| Польза | варды/мин (.40), уничтожено вардов/мин (.20), секунд контроля/мин (.25), стаки/мин (.15) |

Смерти считаются с поправкой: поздняя смерть (к 40-й минуте) стоит вдвое дороже ранней, смерть вне командного боя ещё в 1.25 раза дороже. «Польза» и участие в боях считаются только для обработанных матчей.

**Веса категорий.** core: бой .35, экономика .30, команда .17, здания .13, польза .05. support: .18 / .08 / .39 / .15 / .20. Роль не определена: .30 / .24 / .26 / .12 / .08. Недоступные показатели и категории исключаются, веса пересчитываются.

**Вклады.** Каждый показатель вносит в рейтинг `эффективный_вес · (оценка − 50)` очков; сумма вкладов равна `рейтинг − 50`.

**Доверие и погрешность.** Доверие (0–1) складывается из доли использованных показателей (.35), доли показателей с бенчмарком (.30), размера сравниваемой группы (.15) и длительности матча (.20). Погрешность `± (2 + 10·(1 − доверие))`.

**MVP.** Игрок с наивысшим рейтингом среди победителей; если рейтинг посчитать нельзя — лучший KDA среди победителей (помечается явно).

**Ограничения.** Нет данных о видении и позициях в момент смертей. Веса подобраны разумно и не калибровались на большой выборке реальных матчей. Изменение формулы повышает версию.
