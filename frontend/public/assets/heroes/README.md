# Аватарки героев

Имя файла — короткое имя героя из ссылки CDN Steam, пример: `antimage.png`,
`axe.png`, `doom_bringer.png`, `abyssal_underlord.png`.

Также принимается вариант с префиксом Valve: `npc_dota_hero_antimage.png`.
Формат: .png (можно .jpg/.webp — но имя должно совпадать с оригиналом целиком, включая расширение).
