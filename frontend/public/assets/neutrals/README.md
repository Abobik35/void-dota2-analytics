# Иконки нейтралок (нейтральных предметов / токенов)

Имя файла — ключ предмета из ссылки CDN Steam, пример: `trident.png`,
`titan_silencer.png`, `unwavering_condition.png`.

Их ключи такие же, как у обычных предметов, поэтому иконку нейтралки можно
положить и в `items/` — поиск идёт по обеим папкам.
