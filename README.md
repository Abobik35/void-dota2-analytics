# VOID — Dota 2 Analytics

Аналитика матчей Dota 2: вставляешь Match ID — получаешь разбор игры до последней минуты: вклад каждого игрока, переломные моменты, MVP и потерянные ресурсы.

Данные — из открытого API [OpenDota](https://www.opendota.com/). Сайт не официальный и не связан с Valve.

| Что внутри | Как это выглядит |
|---|---|
| **Разбор матча** | Обзор с MVP, вкладки: игроки, экономика (график золота/опыта/нетворта по минутам), командная статистика, предметы, способности, ход матча, ошибки |
| **VOID Rating** | Собственная оценка вклада игрока 0–100 по четырём категориям (бой, экономика, команда, здания); 50 — средний уровень для роли |
| **Профили игроков** | История матчей с фильтрами (период, герой), форма (W/L полоска), герои в выборке, рекорды |
| **Сравнение игроков** | Два профиля бок о бок: win rate, герои, общие матчи |
| **Поиск по нику** | Искать игрока можно прямо в шапке — без знания Account ID |
| **Вход через Steam** | Необязателен: возвращается после входа (OpenID, без пароля — только подтверждение личности на сайте Steam) |

Иконки героев, предметов и способностей лежат локально (`frontend/public/assets`, ~60 МБ в репозитории) — сайт не зависит от Steam CDN.

## Технологии

- **Backend:** Python 3.10+, FastAPI, SQLAlchemy (SQLite — сессии Steam и кеш ответов OpenDota)
- **Frontend:** React 19 + Vite, TanStack Query, Recharts, Tailwind-free CSS (`src/styles/void.css`)
- **Деплой:** один Docker-контейнер (FastAPI отдаёт собранный фронтенд), хостинг — Back4App Containers; запасной вариант — Render (`render.yaml`)

## Локальный запуск

Нужны Python 3.10+ и Node.js 18+. На Windows — один файл:

1. Запустите `start.bat` — подготовит окружение, поднимет backend (API: `http://localhost:8000`, Swagger: `http://localhost:8000/docs`) и frontend (сайт: `http://localhost:5173`).
2. Откроется сайт — вставьте Match ID (ID есть в адресе любого матча Dotabuff/OpenDota).

Остановка — закрыть окна «VOID backend» и «VOID frontend». Отдельные `start_backend.bat` и `start_frontend.bat` тоже рабочие.

Тесты backend:

```sh
cd backend
.venv\Scripts\python.exe -m pytest -q --ignore=tests/test_rating.py
```

(`tests/test_rating.py` — устаревший тест первого коммита, падает независимо от кода.)

Проверка типов frontend: `npx tsc --noEmit` из папки `frontend/`.

## Публикация в интернете (Back4App Containers, free tier)

Деплой из GitHub-репозитория одним контейнером по готовому `Dockerfile`.

1. Разверните репозиторий на [back4app.com](https://www.back4app.com/) (Containers → Deploy from GitHub).
2. Добавьте переменные окружения:
   - `SECRET_KEY` — произвольная длинная случайная строка (подпись cookies);
   - `PUBLIC_URL` — после первого деплоя укажите фактический адрес (например `https://void-xxx.back4app.io`), от него зависит возврат после входа через Steam; сервис перезапустится сам.
3. Ссылку из статуса контейнера можно отправлять друзьям.

Free tier: сервисы бесплатного плана не резервируют трафик заранее — упираемся в лимит OpenDota (60 запросов/мин без API-ключа; `OPENDOTA_API_KEY` поднимает его). SQLite-база (`void.db`) не переживает пересоздание контейнера — после пересборки просто заново войдите через Steam.

## Частые вопросы

**Что такое VOID? Разве это не Ability Void / Faceless Void?**
VOID — неофициальный сайт-аналитик; название — отсылка к «чёрной дыре» (отсюда и тема дизайна). Skill Faceless Void'а тут ни при чём.

**Это безопасно? Что даёт вход через Steam?**
Пароль никогда не попадает на сайт: вход — это стандартный Steam OpenID, вы подтверждаете логин на сайте Steam, а VOID получает только ваш Steam ID. Ничто не публикуется публично; без входа сайт работает так же, просто без «моих матчей».

**Откуда берутся данные?**
Из открытого API [OpenDota](https://www.opendota.com/) — того же, на котором работает сам OpenDota и часть сторонних сервисов. VOID ничего не отправляет в Valve: обработку реплея сайт запрашивает у OpenDota.

**Почему матч показывает не всё — «Матч не обработан»?**
Для свежих или старых матчей OpenDota ещё не распарсил реплей. Нажмите «Запросить обработку» — обычно 30–60 секунд. Если реплей уже удалён Valve (старше недели), данные по минутам не восстановятся в принципе.

**Почему у игрока звание "звание скрыто"?**
Игрок мог закрыть свой MMR в настройках конфиденциальности Dota 2 — тогда ни OpenDota, ни кто-либо ещё не знает его звания.

**Match ID где взять?**
В адресной строке Dotabuff/OpenDota (число в конце ссылки) или в игре: матч → скопировать ID Match.

**Почему счётчик «выборка: 100 последних матчей», а не вся история?**
Аналитика считается по последним 100 матчам с учётом фильтров — компромисс между глубиной разбора и лимитами OpenDota (60 запросов/мин).

**Сайт зависает / иконки не грузятся / старая версия после обновления.**
- Обновите страницу Ctrl+F5 (кеш браузера).
- Актуальная версия видна по бейджу в шапке (`v0.16.0`).
- Если иконки не загрузились из локальных assets, автоматически подтягиваются с Steam CDN — это фолбэк, а не баг.

**У меня свой сервер/хостинг — как развернуть?**
Нужен любой хостинг, умеющий собирать docker-образ: `docker build` по `Dockerfile` (порт через переменную `PORT`, …). Или запуск «двумя процессами»: backend uvicorn + раздача статики `frontend/dist` любым веб-сервером с SPA-фолбэком (как это устроено, смотри в `backend/app/main.py`).

**Я — фронтендер/бэкендер, где что лежит?**
Backend: `backend/app/` (роуты в `api/routes/`, логика в `services/`), верифицируемый OpenAPI — `http://localhost:8000/docs`. Frontend: `frontend/src/` (страницы в `pages/`, компоненты в `components/`, стили — один файл `styles/void.css`). Версия сайта — в шапке (`vX.Y.Z`), она же в Patch Notes (кнопка в шапке).
