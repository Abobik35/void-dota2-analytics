# VOID DOTA 2 ANALYTICS

Аналитика матчей Dota 2: разбор матча (вкладки с предметами, прокачкой способностей, ошибками), профили игроков, сравнение, VOID Rating. Данные — OpenDota.

Нужны Python 3.10+ и Node.js 18+.

## Локальный запуск

1. Запустите `start.bat` — он сам подготовит окружение, запустит backend (API: http://localhost:8000, Swagger: http://localhost:8000/docs) и frontend (сайт: http://localhost:5173) и откроет сайт в браузере.
2. Введите Match ID на главной странице.

Остановить приложение — закрыть открывшиеся окна «VOID backend» и «VOID frontend». Отдельные `start_backend.bat` и `start_frontend.bat` тоже остались рабочими.

Тесты backend: `cd backend`, `.venv\Scripts\python.exe -m pytest -q --ignore=tests/test_rating.py` (последний — устаревший тест первого коммита, падает независимо от кода).

## Публикация в интернете (Render, free tier)

Один сервис: FastAPI раздаёт и API, и собранный фронтенд. Код уже готов — нужен только аккаунт.

1. Залейте репозиторий на GitHub (он уже подключен как `origin`).
2. https://dashboard.render.com → **New + → Blueprint** → выберите этот репозиторий — конфигурация подхватится из `render.yaml`.
3. При создании Render спросит `PUBLIC_URL` — оставьте пустым на первый деплой; после него поменяйте `PUBLIC_URL` на фактический адрес сервиса (например `https://void.onrender.com`) — от него зависит возврат после входа через Steam. Render перезапустит сервис сам.
4. Ссылку вида `https://<имя-сервиса>.onrender.com` можно отправлять друзьям.

Тонкости free tier:
- сервис **засыпает** после ~15 минут без запросов и просыпается 30–60 секунд — первая загрузка сайта может быть медленной;
- файловая база (`void.db`) не переживает пересоздание контейнера: авторизованные сессии сбрасываются, надо просто снова войти через Steam;
- OpenDota без API-ключа — 60 запросов/минуту; для компании хватит, ключ добавляется в переменные окружения как `OPENDOTA_API_KEY`.

Как это устроено: `render.yaml` собирает фронтенд (`npm run build`) и кладёт `frontend/dist` в `backend/static`; сервер при старте, если папка существует (`FRONTEND_DIST=static`), раздаёт статику и отдаёт `index.html` на любые неизвестные пути — рефреш на `/player/123` или `/match/456` работает.
